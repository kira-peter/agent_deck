# 测试指南：开启新项目

## 功能概述

Projects 视图顶部的"开启新项目"选项会打开一个类似 macOS Finder 的 Miller Columns 目录浏览器，选定目录后在新终端窗口运行 `claude <路径>`。

## 涉及代码

| 文件 | 作用 |
|---|---|
| `pkg/views/dirpicker/models.go` | 数据结构定义 |
| `pkg/views/dirpicker/windows.go` | Windows 驱动器检测和路径处理 |
| `pkg/views/dirpicker/navigation.go` | 目录导航逻辑 |
| `pkg/views/dirpicker/render.go` | 多列渲染与确认对话框 |
| `pkg/views/dirpicker/dirpicker.go` | 视图入口与事件分发 |
| `pkg/views/projects/projects.go` | 模态调起目录选择器 |
| `pkg/i18n/translations.go` | 相关文案 |

## 测试步骤

### 1. 启动应用
```powershell
cd D:\jarvis\claude_manager
make build
.\build\claude-manager.exe
```

### 2. 进入 Projects 视图
- 在主菜单用上下键选择 "Projects" / "项目"
- 按 Enter 进入

### 3. 测试新项目选项
**验证点**：
- ✓ 列表顶部应显示 `[+] 开启新项目`（绿色高亮）
- ✓ 使用上键可以选中它（变为深绿色背景）
- ✓ 下方有分隔线，然后是现有项目列表

### 4. 测试目录选择器启动
**操作**：选中"开启新项目"，按 Enter

**验证点**：
- ✓ 全屏切换到目录选择器界面
- ✓ 标题显示"选择项目目录"
- ✓ 右上角显示"ESC: 取消"
- ✓ 左侧第一列显示"驱动器"
- ✓ 列出所有可用驱动器（C:\, D:\, 等）

### 5. 测试导航功能

#### 5.1 右方向键 - 进入目录
**操作**：
1. 选中 `D:\`（或任意驱动器）
2. 按右方向键

**验证点**：
- ✓ 新增第二列，显示 D 盘根目录内容
- ✓ 目录显示为 `> 目录名/`
- ✓ 文件显示为 `  文件名`
- ✓ 目录在前，文件在后
- ✓ 第二列边框变为浅青色（激活状态）

#### 5.2 上下方向键 - 列内导航
**操作**：
1. 在当前列使用上下键移动

**验证点**：
- ✓ 选中项高亮（绿底黑字）
- ✓ 只在当前列中移动
- ✓ 其他列不受影响

#### 5.3 继续右键 - 深入目录
**操作**：
1. 选中一个目录（如 `jarvis/`）
2. 按右键进入
3. 再选一个子目录，按右键

**验证点**：
- ✓ 每次右键都添加新列到右侧
- ✓ 最多显示 5 列
- ✓ 超过 5 列时，左侧列滚动隐藏
- ✓ 当前路径栏显示完整路径
- ✓ 激活列边框始终为浅青色

#### 5.4 左方向键 - 返回上级
**操作**：
1. 在深层目录，按左方向键

**验证点**：
- ✓ 移除当前列右侧的所有列
- ✓ 焦点移回上级列
- ✓ 当前路径更新为上级路径

#### 5.5 Vim 风格键位
**操作**：测试 h/j/k/l

**验证点**：
- ✓ `h` = 左键（返回上级）
- ✓ `l` = 右键（进入目录）
- ✓ `k` = 上键（向上移动）
- ✓ `j` = 下键（向下移动）

### 6. 测试特殊情况

#### 6.1 权限不足
**操作**：
1. 导航到 `C:\System32\config\`
2. 尝试进入（如果有权限问题）

**验证点**：
- ✓ 显示 `<权限不足>` 条目（红色）
- ✓ 无法进入
- ✓ 可以返回上级

#### 6.2 空目录
**操作**：
1. 创建一个空目录：`New-Item -ItemType Directory -Path D:\test-empty`
2. 导航到并进入该目录

**验证点**：
- ✓ 显示 `<空目录>` 提示
- ✓ 仍然可以选择该目录（按 Enter）

#### 6.3 隐藏文件
**操作**：导航到包含 `.git/` 等隐藏目录的项目

**验证点**：
- ✓ 隐藏文件/目录显示为灰色
- ✓ 可以正常进入

#### 6.4 长文件名
**操作**：导航到包含很长文件名的目录

**验证点**：
- ✓ 超长文件名被截断，末尾显示 `...`
- ✓ 不影响布局

#### 6.5 文件选择
**操作**：选中一个文件，按右键

**验证点**：
- ✓ 无反应（只能进入目录）

### 7. 测试目录选择和确认

#### 7.1 选择目录
**操作**：
1. 导航到目标目录（如 `D:\jarvis\test-project`）
2. 按 Enter 键

**验证点**：
- ✓ 显示确认对话框（选项模式）
- ✓ 标题："在此目录中打开 Claude Code?"（黄色粗体）
- ✓ 显示完整路径（白色）
- ✓ 显示两个选项，每个占一行：
  - `>  是，打开` - 默认选中（绿底黑字）
  - `   否，重新选择` - 未选中（白字）
- ✓ 底部显示操作提示："↑↓/jk: 移动  Enter: 确认  ESC: 返回"（灰色）

#### 7.2 选项导航
**操作**：
1. 按下方向键移动选择
2. 测试 j/k（Vim 风格）

**验证点**：
- ✓ 选中项变为绿底黑字，前缀为 `>  `（箭头 + 两个空格）
- ✓ 未选中项为白字，前缀为三个空格
- ✓ 可以在两个选项之间来回切换
- ✓ j/k 键与上下键功能相同

#### 7.3 确认打开 - Enter 键
**操作**：
1. 使用上下键选中"是，打开"
2. 按 Enter 键

**验证点**：
- ✓ 应该启动新的终端窗口
- ✓ 新窗口运行 `claude D:\jarvis\test-project`
- ✓ claude-manager 应退出

#### 7.4 取消重选 - Enter 键
**操作**：
1. 选择一个目录，按 Enter
2. 用上下键选中"否，重新选择"
3. 按 Enter 键

**验证点**：
- ✓ 返回目录选择器
- ✓ 保持在之前选择的目录位置
- ✓ 可以继续导航到其他目录

#### 7.5 完全取消 - ESC 键
**操作**：
1. 选择一个目录，按 Enter
2. 在确认对话框按 ESC

**验证点**：
- ✓ 直接返回 Projects 列表（不是返回目录选择器）
- ✓ 没有启动 Claude Code

#### 7.6 验证快捷键已移除
**操作**：
1. 在确认对话框尝试按 `Y` 键
2. 尝试按 `N` 键

**验证点**：
- ✓ Y/N 键不再有任何效果
- ✓ 必须用上下键选择后按 Enter 确认

### 8. 测试取消流程

#### 8.1 在选择器中按 ESC
**操作**：在目录选择器中按 ESC

**验证点**：
- ✓ 立即返回 Projects 列表
- ✓ 没有确认对话框

#### 8.2 在选择器中按 Q
**操作**：在目录选择器中按 `Q`

**验证点**：
- ✓ 同样返回 Projects 列表

### 9. 测试现有功能不受影响

**验证点**：
- ✓ 现有项目列表正常显示
- ✓ 可以选择现有项目并打开
- ✓ 删除功能正常（按 D）
- ✓ 刷新功能正常（按 R）
- ✓ ESC 返回主菜单正常
- ✓ Q 退出应用正常

### 10. 测试中英文切换

**操作**：
1. 在 Projects 视图按 `T` 切换到英文
2. 进入"开启新项目"

**验证点**：
- ✓ 所有文本切换为英文：
  - "Select Project Directory"
  - "Drives"
  - "Current: ..."
  - "←→: Navigate  ↑↓: Move  Enter: Select  ESC: Cancel"
  - "<Permission Denied>"
  - "<Empty Directory>"
  - "Open Claude Code in this directory?"
  - ">  Yes, Open"
  - "   No, Choose Another"
  - "↑↓/jk: Move  Enter: Confirm  ESC: Back"

## 已知限制

1. **最大列数**：最多同时显示 5 列（更深的路径会滚动）
2. **最小终端宽度**：需要至少 60 列宽度
3. **系统目录跳过**：自动跳过 `$Recycle.Bin`, `System Volume Information` 等系统目录

## 清理测试数据

```powershell
# 删除测试创建的空目录
Remove-Item -Path D:\test-empty -Force -ErrorAction SilentlyContinue
```
