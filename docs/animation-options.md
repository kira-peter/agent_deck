# 10个经典终端动画选项

## 推荐列表（按视觉效果和兼容性排序）

### 1. 弹跳球 (Bouncing)
```
˙ → · → ∘ → ○ → ◯ → ○ → ∘ → ·
```
- **效果**: 圆点从小到大再到小，模拟弹跳
- **风格**: 轻快、活泼
- **宽度**: 一致

### 2. 脉冲波 (Pulse)
```
· → ∘ → ○ → ◯ → ◉ → ◯ → ○ → ∘
```
- **效果**: 圆圈从中心向外扩散
- **风格**: 平滑、渐进
- **宽度**: 一致

### 3. 三角旋转 (Triangle)
```
◢ → ◣ → ◤ → ◥
```
- **效果**: 三角形顺时针旋转
- **风格**: 简洁、几何
- **宽度**: 一致

### 4. 方块翻转 (Square)
```
◰ → ◳ → ◲ → ◱
```
- **效果**: 方块内部图案旋转
- **风格**: 规整、对称
- **宽度**: 一致

### 5. 圆圈旋转 (Circle)
```
◴ → ◷ → ◶ → ◵
```
- **效果**: 圆圈四分之一旋转
- **风格**: 流畅、连续
- **宽度**: 一致

### 6. 沙漏 (Hourglass)
```
⏳ → ⌛ → ⏳ → ⌛
```
- **效果**: 经典的时间流逝
- **风格**: 传统、优雅
- **宽度**: emoji，较宽

### 7. 蛇形移动 (Snake)
```
⠁ → ⠂ → ⠄ → ⡀ → ⢀ → ⠠ → ⠐ → ⠈
```
- **效果**: Braille 点像蛇爬行
- **风格**: 灵动、有趣
- **宽度**: 一致

### 8. 音符跳动 (Music)
```
♩ → ♪ → ♫ → ♬
```
- **效果**: 音乐符号跳跃
- **风格**: 欢快、节奏
- **宽度**: 一致

### 9. 心跳 (Heart)
```
♡ → ♥ → ❤ → ♥
```
- **效果**: 心形变化
- **风格**: 浪漫、温馨
- **宽度**: 一致

### 10. 时钟旋转 (Clock)
```
🕐 → 🕑 → 🕒 → 🕓 → 🕔 → 🕕 → 🕖 → 🕗 → 🕘 → 🕙 → 🕚 → 🕛
```
- **效果**: 时针转动一圈
- **风格**: 精确、传统
- **宽度**: emoji，较宽

---

## 使用建议

### 推荐优先级：

**宽度一致、视觉清晰** (最推荐)：
1. ✅ 弹跳球 (Bouncing)
2. ✅ 脉冲波 (Pulse)
3. ✅ 三角旋转 (Triangle)
4. ✅ 方块翻转 (Square)
5. ✅ 圆圈旋转 (Circle)

**特殊效果** (次推荐)：
6. ⚠️ 沙漏 (Hourglass) - emoji 较宽
7. ✅ 蛇形移动 (Snake)
8. ✅ 音符跳动 (Music)
9. ✅ 心跳 (Heart)
10. ⚠️ 时钟旋转 (Clock) - emoji 较宽

**注意**: emoji 动画（沙漏、时钟）在某些终端可能显示较宽，可能影响对齐。
